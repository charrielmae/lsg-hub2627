# Custom Font Files Drop-in Directory

Drop your licensed/local font files into this folder (`frontend/public/fonts/`) using the filenames below. `src/app/globals.css` is pre-configured with `@font-face` rules that automatically prioritize these files and fall back cleanly to Google Fonts until they are added:

1. **Display — MM Rachel**
   - `MMRachel-Regular.woff2` (or `MMRachel-Regular.otf` / `MMRachel-Regular.ttf`)
2. **Headline — Stara Medium**
   - `Stara-Medium.woff2` (or `Stara-Medium.otf` / `Stara-Medium.ttf`)
3. **Subtext — ABC Monument Grotesk Mono**
   - `ABCMonumentGroteskMono-Regular.woff2` (or `ABCMonumentGroteskMono-Regular.otf` / `ABCMonumentGroteskMono-Regular.ttf`)
